# Apple Homepage Clone

A static recreation of the Apple homepage built with HTML and CSS as part of a frontend development assignment.

## About

This project recreates the desktop version of the Apple homepage, focusing on layout, spacing, typography, banners, product cards, navigation, and footer sections.

## Technologies

- HTML5
- CSS3

## Assignment

This project was created as an assignment for **SMIT (Saylani Mass IT Training)**.
